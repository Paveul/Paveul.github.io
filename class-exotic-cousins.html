Exotic Cousins of Integers

Maths Beyond Limits, Falenty

Ever got angry that there is no way to factorize x² + y², my friend? Come to the dark side, where we treat i = √-1 as if it were an integer, and the power of unique factorization let's you solve equations like y² = x³ - 1. But beware: not much further lay treacherous territories, like that of √-5, where you can have 2 · 3 = (1 - √-5) · (1 + √-5) with all factors irreducible!

This class aims to arm you with the algebraic language of rings needed to explore these exotic 'cousins' of integers. Discover which primes can be expressed as x² + 2y², and learn about an 1847 failed attempt to prove Fermat's Last Theorem—and how it actually works for x³ + y³ = z³.
