# Paveul.github.io

Minimalistic personal business page — quantitative research & consulting.

Built with plain HTML, CSS, and a sprinkle of JavaScript. Hosted on [GitHub Pages](https://paveul.github.io).

## Local development

Open `index.html` in a browser, or serve with:

```bash
npx serve .
```

## Customisation

Edit the CSS custom properties at the top of `css/style.css` to change colours, fonts, and spacing across the entire site.
